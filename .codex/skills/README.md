# Rate Skill Pack

This directory contains the project skill pack for the Rate repository.

## Project Skills

- `rate-backend-api`: .NET Clean Architecture backend, CQRS, endpoints, DI, auth, payments, caching.
- `rate-frontend-next`: Next.js App Router frontend, UI registry, Tailwind v4, API client usage.
- `rate-ai-agent`: AI chat, Semantic Kernel, Gemini/OpenAI/Ollama, embeddings, pgvector search.
- `rate-auth-security`: Identity, JWT, refresh tokens, Redis revocation, auth UI, protected APIs.
- `rate-data-ops`: EF Core, migrations, seed data, PostgreSQL/pgvector, Redis-backed data services.
- `rate-domain-booking`: movie, theater, show, booking, payment, review domain workflows.
- `rate-testing-quality`: backend NUnit/Shouldly tests, frontend Playwright, lint/build validation.
- `rate-infra-deploy`: Aspire AppHost, Azure Bicep/azd, appsettings, local/cloud service configuration.

## Downloaded Curated Skills

- `aspnet-core`
- `playwright`
- `security-best-practices`
- `security-threat-model`
